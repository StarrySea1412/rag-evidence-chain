## 这一篇在讲什么

大多数 RAG 项目死在同一个地方：它答得像对的。给它一条专利权利要求，它会给你一段读起来很专业的总结，引用三段原文，语气笃定；你抽查第一段，发现引用的段落里根本没有那个限定语。

这篇不写「怎么把向量库接上大模型」——那部分一晚上就能做完。它写更难的一半：**怎么把一次检索变成可以判定、可以拒答、可以复算的证据**。

载体任务：给定一条权利要求，从一批对比文件里找出每个技术特征对应的原文段落，逐条留证，找不到就拒答。

## 四枚小样

| 小样 | 位置 | 数据性质 |
|---|---|---|
| 01 切分边界 | 第 2 章 | **虚构示例文本 + 示意构造**：5 条编写的虚构特征（通用专利句式，不指向任何真实专利）的几何切分，演示「刀口落在特征区间内」 |
| 02 混合召回与重排 | 第 3 章 | **示意分值**：手写 6 条段落的向量/BM25/重排分，演示「加一路会挤掉另一路」 |
| 03 检索预算 | 第 3 章 | **示意曲线**：召回 `0.97×(1−e^(−k/2.2))`，准确率为见顶回落的经验式 |
| 04 Wilson 区间 | 第 6 章 | **真实计算**：Wilson 95% 区间，公式可复算，无示意值 |

> 只有第 4 枚是真实计算。另外三枚的数值是构造的，用来让机制可见；**请勿把示意值当作实测结果引用**。

## 一个真实可复算的例子

```
3/19  -> 15.8%  [ 5.5%, 37.6%]
5/19  -> 26.3%  [11.8%, 48.8%]
```

两个区间大面积重叠 → 3/19 与 5/19 的差异**不显著**。
所以「提升了 67%」这种说法在小样本下不成立。第 6 章那枚小样可以手动验证。

## 边界与免责
